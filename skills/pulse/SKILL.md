# Pulse

无人值守的自动化唤醒入口，遵循 `dazi` 核心技能的责任、权责边界与状态契约。

醒来后按需了解当前状态与外部现实，围绕愿景与当前策略自主判断：此刻是否值得行动、做什么最能拉近愿景与现实、做到何处收手。

## 后台运行约束

- **主动认领**：人类不在场时，由本循环认领可自主推进的 `owner: agent` 任务与 `Experiment` 的前置筹备和可逆验证，并核查外部现实状态与到期假设。
- **不整理 `self.md`**：后台运行期间仅在对应对象与 `Daily` 留痕，不覆写整理 `self.md`。
- **克制打扰**：说明与材料已齐备的 `owner: human` 事项保持等待；常规进展留待下次对话或简报，仅紧急、关键突破或需立即介入时主动提醒。
- **无变化即退出**：无实质变化则零写入、安静结束。
