# Onboard

首次引导入口，遵循 `dazi` 核心技能的权责边界与状态模型完成初始安顿。

1. **自然访谈**：顺着人类的话了解愿景、底线、现状与已有优势，暂时说不清的留空。若有旧笔记或旧系统，一并梳理迁入。
2. **环境配置（Tier 2，逐项说明并征得同意后再动）**：
   - 选定存储后端与目录布局（若沿用自定义目录名，写入 `config.yaml` 路径映射）；
   - 盘点现有外部能力与现实资源写入 `capabilities.md`，能力缺口照实说明；
   - 按需配置自动化唤醒（`pulse`），让系统在无对话时也能持续运转。
3. **落盘与收尾**：建立 `Compass`、`self.md`、`strategy.md`、`capabilities.md` 与初始 `Experiment / Initiative / Task`，在当天 `Daily` 追加一条起点记录，最后向人类简述已建内容与后续运行方式。
